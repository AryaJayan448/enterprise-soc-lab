# Enterprise SOC Lab using Microsoft Sentinel & Splunk

## Overview

This project is about building an Enterprise Security Operations Center (SOC) lab using Microsoft Sentinel and Splunk. By building this lab, I will gain hands-on experience in SOC operations, including threat detection, incident investigation, and responding to cyber threats, while creating professional documentation to showcase my skills and learning.
